# 🎮 Як почати грати
Ласкаво просимо до Кубічного Вікі! Цей посібник допоможе вам підключитися до нашого сервера Minecraft та почати свою пригоду.

## Встановлення Java
По-перше, переконайтеся, що у вас встановлена Java версії 17 або новіша. 

**[Завантажити Java 21+](https://adoptium.net/temurin/releases/?version=21&os=windows)**

- Перейдіть за посиланням і завантажуйте відповідний інсталятор для вашої операційної системи.

![Java Installation Screenshot](/images/java.jpg)

- Встановіть Java, слідуючи інструкціям інсталятора.

##  Встановлення Лаунчера

Адміністрація сервера рекомендує використовувати **Prism Launcher** для зручної гри на сервері і швидшим вирішенням можливих проблем.

Є два варіанти лаунчера:
- **[Prism Launcher](https://prismlauncher.org/)** (Ліцензійний)

    - [Завантажити (Інсталятор)](https://github.com/PrismLauncher/PrismLauncher/releases/latest/download/PrismLauncher-Windows-MSVC-Setup-10.0.5.exe)
    - [Завантажити (Портативна версія)](https://github.com/PrismLauncher/PrismLauncher/releases/latest/download/PrismLauncher-Windows-MSVC-Portable-10.0.5.zip)

- **[Prism Launcher Cracked](https://github.com/Diegiwg/PrismLauncher-Cracked/releases/)** (Піратка)

    - [Завантажити (Інсталятор)](https://github.com/Diegiwg/PrismLauncher-Cracked/releases/latest/download/PrismLauncher-Windows-MSVC-Setup-10.0.5.exe)
    - [Завантажити (Портативна версія)](https://github.com/Diegiwg/PrismLauncher-Cracked/releases/latest/download/PrismLauncher-Windows-MSVC-Portable-10.0.5.zip)

## Перший запуск Prism Launcher
- Завантажте та встановіть **Prism Launcher**.
- Відкриваємо лаунчер, в меню обираємо зручну для вас мову.
- Далі обираємо версію **Java 21** або новішу (якщо не бачите, додайте шлях до встановленої Java вручну в налаштуваннях лаунчера).
- Укажіть бажаний обсяг оперативної пам'яті (рекомендується від **4 ГБ** і більше).
- Обираємо тему.
- Натискаємо **Зберегти**.

## Додавання Акаунта
- Натисніть на іконку користувача у верхньому правому куті.
- Вибераємо тип акаунта: **Додати Оффлайн Акаунт** (для піратки) або **Додати Microsoft Акаунт** (для ліцензійного).
- Введіть бажане ім'я гравця та підтвердіть.


## Встановлення рекомендованої збірки
- У лівому верхньому куті натисніть на кнопку **+ Додати Збірку**.
- Перейдіть на вкладку **Modrinth**.
- Оберіть **Fabulously Optimized**(1.21.11) і натисніть **Ок**.
