# 🚀 Moderner Beta

![moderner-beta-logo](/images/mods/moderner-beta.jpg)

**Moderner Beta** — це форк моду *Modern Beta* від `b3spectacled`. Проєкт є частиною ініціативи **Nostalgica Reverie**.

## 🛠 Особливості та Функціонал

Moderner Beta має розширений набір функцій і значні переваги над оригінальним модом.

### Що пропонував оригінальний Modern Beta:

* Генерація світу для старих версій Minecraft: від **Classic 0.30** до **Beta 1.7.3**.
* Ряд користувацьких опцій для зміни форми ландшафту та розподілу біомів.

### Що пропонує Moderner Beta (цей форк):

* **Мультиплатформеність:** Підтримка **NeoForge** та **Forge** на додачу до **Fabric**.
* **Зручність:** Графічне меню налаштувань для простих опцій.
* **Розширена генерація:** Генерація світів від **Beta 1.8** до **Release 1.17.1** з точним розподілом біомів.
* **Додаткові версії:** Генерація з *Infdev 20100325*, *Classic 0.0.14a_08* та *Beta 1.1*.
* **Механіки:** Повернення шумових печер (noise caves) та правил генерації поверхні (surface rules).
* **Кастомізація:** Надзвичайно гнучкий конвеєр фрактальних шарів біомів для версій Beta 1.8+.
* **Модульність:** Модульний підхід до конфігурації, що дає більший контроль для розробників аддонів.
